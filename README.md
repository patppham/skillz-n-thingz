# Daily Skills Library

This repository is the public-safe source of truth for the skills I use across Codex, Antigravity, Opencode, and Hermes.

The main browsing experience is folder-first:

- Workflow area
- Skill folder
- `SKILL.md`

That way GitHub shows the real operating system I use day to day for household and developer work, instead of a flat catalog.

- [docs/workflow-map.md](./docs/workflow-map.md)
  Human-readable summary of the same grouping.

## Authorship Labels

- `mine`
  Custom skill written primarily for my workflow.
- `adapted`
  Based on outside ideas, tools, or shared skill patterns, then customized for my workflow.
- `external`
  Mostly written by others or adopted from a shared skill with minimal local change.

## Publication Status

- `publish`
  Ready to live in the public repo.
- `review`
  Probably publishable, but should be checked for local assumptions first.
- `redact`
  Contains personal, machine-specific, account-specific, or operational details that should be sanitized before publishing.
